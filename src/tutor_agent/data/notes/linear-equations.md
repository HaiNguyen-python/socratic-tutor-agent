# Linear equations

## What it means to solve an equation

An equation says that two expressions are equal, like a balanced scale. To solve it you find
the value of the unknown (often x) that makes both sides equal. Whatever you do to one side,
you must do to the other side, so the scale stays balanced.

## Inverse operations

Undo operations in the reverse order. Addition is undone by subtraction, and multiplication is
undone by division. Example: in 5x + 1 = 16, first subtract 1 from both sides (5x = 15), then
divide both sides by 5.

## Brackets and unknowns on both sides

If there is a bracket, either expand it (multiply every term inside) or divide both sides by
the number in front. If x appears on both sides, subtract the smaller x-term from both sides so
that x is only on one side. Example: 9x = 4x + 10 becomes 5x = 10.

## Check your answer

Substitute your value back into the original equation. If both sides give the same number, the
answer is right. Negative and fractional answers are fine: an equation does not have to have a
whole-number solution.
